# โปสเตอร์ Facebook Thumbnail

ไฟล์หลัก: `facebook-thumbnail.png` ขนาด 1600 × 900 pixels (16:9)

ไฟล์ต้นฉบับแก้ไขข้อความ: `facebook-thumbnail.svg`

ภาพฉากหลังที่สร้างด้วย imagegen: `poster-bg-auto-light-lab.png`

ข้อความบนโปสเตอร์:

- AUTO LIGHT LAB. — ห้องทดลองวงจรไฟรถยนต์
- ต่อวงจรความคิด / จุดติดทุกการเรียนรู้
- เกมการเรียนรู้ระบบไฟรถยนต์
- จับคู่สัญลักษณ์ • ต่อวงจร • วิเคราะห์จุดขัดข้อง
- CODE + GOOGLE SHEETS DATABASE
- ระบบบันทึกผลการเรียนรู้ในอุปกรณ์ของคุณ

## Prompt ฉากหลัง

สร้างภาพพื้นหลังโปสเตอร์ Facebook แบบกว้าง 16:9 สำหรับเกมการเรียนรู้วงจรไฟรถยนต์ โทนเขียวป่าเข้มและ charcoal มีรถสีเงินมุมสามส่วนอยู่ด้านขวา ไฟหน้าสีอำพันสว่าง มีสัญลักษณ์แบตเตอรี่ ฟิวส์ สวิตช์ รีเลย์ หลอดไฟ และกราวด์เป็นแผงวงจรเรืองแสงอยู่ด้านบน พร้อมกริดข้อมูลคล้าย spreadsheet อยู่ด้านหลัง สง่างาม เป็นมิตรกับการเรียนรู้ และมีพื้นที่ว่างด้านซ้ายสำหรับวางตัวหนังสือ ห้ามมีข้อความ ตัวอักษร ตัวเลข โลโก้ ลายน้ำ หรือคนในภาพ
